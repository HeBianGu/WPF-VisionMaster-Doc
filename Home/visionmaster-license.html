版本发行说明

WPF-VisionMaster 5.0.0-preview.1.20260720

产品名称机器视觉通用平台
标题WPF-VisionMaster5.0
目标框架net8.0-windows
版本状态Preview

该版本以 .NET 8 和 WPF 为基础，面向机器视觉流程编排与桌面端应用开发。版本信息读取自 H.App.VisionMaster.csproj。

  • 提供图像、视频、相机、OpenCV、ONNX、检测记录和通信等可视化流程节点能力。
  • 集成项目管理、用户身份、权限角色、主题设置、日志和通用 WPF 控件。
  • 支持 OpenCvSharp4 图像处理、SQLite / SQL Server 数据访问及 JSON 项目序列化。
  • 支持海康工业相机接入；使用相机模块时需安装相应 SDK 并配置运行环境。
