4.0.0

缺陷检测、运行模式与通信能力

本版本新增缺陷检测流程、运行模式页面设计、通信节点、前景矫正节点和用户身份认证，并增强测量与模板匹配模块。

缺陷检测流程

  • 新增独立的缺陷检测深度学习训练工具。
  • 优化目标检测，支持 Yolov8 训练的 ONNX 模型。
  • 新增缺陷检测记录节点，支持查看、导出、自定义报告设计与打印。

运行模式与通信

  • 支持组态拖拽方式设计运行模式页面，并可按用户角色直接进入运行界面。
  • 新增串口、TCP、UDP 和 HTTP 通信节点。

测量、矫正与模板匹配

  • 新增 Shi-Tomasi、Harris 角点查找，以及前景反转矫正、前景信息提取与应用矫正节点。
  • 线线测量支持夹角测量；圆和线段测量支持多种过滤规则。
  • 新增轮廓匹配、特征匹配；像素匹配与颜色匹配完成重命名和编辑体验优化。

其他优化

  • OpenCvSharp4 升级至 4.13.0.20260222。
  • 支持流程循环执行、流程菜单显示控制、九点标定、运行全部与停止全部。
  • 优化识别结果显示、颜色选择和部分模块的内存泄漏问题。

3.0.0

测量体系、工业相机与流程灵活性升级

版本围绕测量能力、流程灵活性、工业相机接入、参数表达式与全局变量、可视化交互和许可管控展开。

  • 新增卡尺绘制以及点、线、圆等几何要素测量，覆盖线线、线圆、圆圆、点线、点圆和点点关系。
  • 新增海康 MVS 相机管理与相机节点。
  • 新增参数表达式系统和字符串、整型、浮点型全局参数中心。
  • 图像列表提供 22 种布局，支持同步缩放、多阶段结果对比和前序图像结果选择。
  • 新增运行/开发双许可控制、节点替换、圆查找、逻辑循环节点、颜色吸管与长度卡尺工具。
  • 优化 ROI 复用、矢量化识别结果显示、像素块渲染、多前驱等待和参数表达式缓存。

2.0.0

ONNX 推理、通信与流程控制扩展

  • 优化流程图，增加 ROI 绘制、条件分支节点和运行模式页面。
  • 新增分类、推算、目标识别、语义分割等 ONNX 通用解析模块及内置模型。
  • 新增 Modbus 数据采集、监控与发送能力。
  • 优化相机数据源、模板匹配和图像预处理节点。
  • 新增多组图像资源、当前模块结果与 NG、OK、运行、错误、成功等结果输出节点。
  • 升级到 .NET 8 长期支持版本。

1.0.0

OpenCV 核心视觉功能与基础工程能力

  • 支持 RGB、HSV、Gray 等多种色彩空间转换。
  • 支持实时视频和视频文件的帧捕获与图像处理。
  • 提供高斯、中值、双边滤波、形态学操作和边缘检测等经典算法。
  • 支持自定义视觉处理算法节点扩展。
  • 支持多工程、示例模板、拖拽式流程设计、流程模板保存调用、主题定制和统一系统配置。
