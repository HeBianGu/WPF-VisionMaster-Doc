版本发行说明

WPF-VisionMaster V5.0.0

产品名称WPF-VisionMaster
标题WPF-VisionMaster V5.0
目标框架net8.0-windows
版本状态Release

该版本围绕插件化算子架构、设备管理、流程运行增强、视觉工具扩展和交互体验优化进行升级，进一步提升机器视觉平台的扩展能力、工程化能力与使用体验。

  • 重构流程算子加载机制，将主要视觉功能拆分为独立插件，并新增插件管理、OpenCV 与 Halcon 插件示例。
  • 内置 19 个插件模块、20 个功能分组和 222 个流程模块，覆盖采集、定位、测量、识别、缺陷检测、标定、运算、颜色处理、通信、ONNX 与 YOLO 等场景。
  • 新增主页、通信管理、全局相机、全局触发、电脑性能监控和消息日志，统一管理工程入口与设备资源。
  • 增强流程连续执行、图像切换自动运行、多流程启停、流程局部变量和流程快速切换能力。
  • 优化参数表达式，支持直接输入、表达式编辑、参数值预览和结果对象属性设置。
  • 新增二维码、条形码、字符识别、YOLO 检测、相机标定、位置修正、Blob 分析、颜色处理、坐标运算和光源模拟等算子。
  • 完善图像位置与像素信息查看、结果文本叠加、发行历史、第三方依赖项和插件信息展示。
