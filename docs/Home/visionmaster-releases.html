5.0.0

插件化算子架构、设备管理与流程运行升级

本版本围绕插件化算子架构、设备管理、流程运行增强、视觉工具扩展和交互体验优化五个方向进行升级，进一步提升平台的扩展能力、工程化能力与使用体验。

插件化架构升级

  • 重构流程算子加载机制，将大部分视觉功能拆分为独立插件，支持按模块加载和扩展。
  • 新增插件管理功能，统一展示和管理已安装的算子插件。
  • 新增 OpenCV 与 Halcon 插件示例，为自定义视觉算法和第三方算法接入提供参考。
  • 当前内置 19 个插件模块、20 个功能分组，共计 222 个流程模块。
  • 模块及算子设计主要参考 VisionMaster，部分算子由 AI 辅助生成，后续版本将持续优化实现方式、参数定义和处理逻辑。

主页与设备管理升级

  • 新增主页，集中提供工程入口、设备管理、帮助信息和常用功能。
  • 新增通信管理，统一维护流程使用的通信设备及连接配置。
  • 重构相机管理并采用全局相机模式，实现相机资源统一配置、共享与调用。
  • 新增全局触发机制、电脑性能监控，并增强消息日志功能。

流程运行与交互增强

  • 新增流程连续执行模式；切换图像后可自动执行流程。
  • 优化自动切换、运行全部和停止全部逻辑，提升多流程运行的稳定性与一致性。
  • 流程图列头支持下拉切换当前流程，并新增流程局部变量。
  • 参数表达式支持直接输入参数值、编辑表达式、预览参数值及设置结果对象属性。
  • 增强图像交互，可显示鼠标位置和像素信息；结果图像支持叠加文本并按分组管理显示参数。

新增与增强算子模块

  • 通信：接收数据、发送数据、协议解析、协议组装和相机 IO 输出。
  • YOLO：目标检测、旋转框检测、姿态评估和图像分割，并基于 YoloSharp 6.0.7 提供分类。
  • 标定：N 点标定、平移旋转标定、位置修正、标定文件加载、棋盘标定板、圆形标定板和畸变校正。
  • 识别与定位：二维码识别、条形码识别、字符识别、灰度匹配、Blob 分析和位置修正。
  • 运算与颜色：单点抓取、单点修正、变量计算、旋转计算、坐标变换、单位转换、点集对齐、颜色识别、颜色测量和颜色分割。
  • 新增基础、几何和环境等光源模拟模块。

功能规模与帮助信息

  • 覆盖采集、定位、测量、识别、缺陷检测、标定、运算、颜色处理、图像处理、逻辑工具、通信、ONNX 和 YOLO 等 20 个功能分组。
  • 新增发行历史说明页和第三方依赖项页面，完善许可、发行说明与插件信息展示。

4.0.0

缺陷检测、运行模式与通信能力

本版本新增缺陷检测流程、运行模式页面设计、通信节点、前景矫正节点和用户身份认证，并增强测量与模板匹配模块。

缺陷检测流程

  • 新增独立的缺陷检测深度学习训练工具。
  • 优化目标检测，支持 Yolov8 训练的 ONNX 模型。
  • 新增缺陷检测记录节点，支持查看、导出、自定义报告设计与打印。

运行模式与通信

  • 支持组态拖拽方式设计运行模式页面，并可按用户角色直接进入运行界面。
  • 新增串口、TCP、UDP 和 HTTP 通信节点。

测量、矫正与模板匹配

  • 新增 Shi-Tomasi、Harris 角点查找，以及前景反转矫正、前景信息提取与应用矫正节点。
  • 线线测量支持夹角测量；圆和线段测量支持多种过滤规则。
  • 新增轮廓匹配、特征匹配；像素匹配与颜色匹配完成重命名和编辑体验优化。

其他优化

  • OpenCvSharp4 升级至 4.13.0.20260222。
  • 支持流程循环执行、流程菜单显示控制、九点标定、运行全部与停止全部。
  • 优化识别结果显示、颜色选择和部分模块的内存泄漏问题。

3.0.0

测量体系、工业相机与流程灵活性升级

版本围绕测量能力、流程灵活性、工业相机接入、参数表达式与全局变量、可视化交互和许可管控展开。

  • 新增卡尺绘制以及点、线、圆等几何要素测量，覆盖线线、线圆、圆圆、点线、点圆和点点关系。

  • 优化 ROI 复用、矢量化识别结果显示、像素块渲染、多前驱等待和参数表达式缓存。
